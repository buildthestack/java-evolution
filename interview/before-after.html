Before → After Java 9 – 27

Side-by-side code comparisons — what you used to write vs. what you write today. Filter by version and feature type. Only stable (non-preview) features included.

24 examples
Private interface methods Java 9 Language
Old
interface Logger {
    default void logInfo(String msg) {
        System.out.println(
            "[INFO] " + timestamp() + msg);
    }
    default void logWarn(String msg) {
        System.out.println(
            "[WARN] " + timestamp() + msg);
    }
    // no way to share logic without
    // exposing a public helper method
}
Modern
interface Logger {
    private String format(String lvl, String msg) {
        return "[" + lvl + "] " + timestamp() + msg;
    }
    default void logInfo(String msg) {
        System.out.println(format("INFO", msg));
    }
    default void logWarn(String msg) {
        System.out.println(format("WARN", msg));
    }
}

JEP 213 — private methods keep shared logic inside the interface without polluting its public API.

JEP 269 — List.of, Set.of, Map.of return compact immutable collections. No need for Guava ImmutableList.

Stream.takeWhile / dropWhile Java 9 API
Old
// No built-in takeWhile — loop manually
List<Integer> result = new ArrayList<>();
for (int n : numbers) {
    if (n >= 10) break;
    result.add(n);
}
Modern
List<Integer> result = numbers.stream()
    .takeWhile(n -> n < 10)
    .toList();

// dropWhile skips until predicate is false
List<Integer> rest = numbers.stream()
    .dropWhile(n -> n < 10)
    .toList();

Works on ordered streams; on unordered streams behaviour is non-deterministic. Useful for processing sorted data up to a threshold.

Optional.ifPresentOrElse / stream() Java 9 API
Old
Optional<User> user = findUser(id);
if (user.isPresent()) {
    send(user.get());
} else {
    log("user not found");
}

// Couldn't compose Optional into a stream pipeline
Modern
findUser(id).ifPresentOrElse(
    this::send,
    () -> log("user not found")
);

// Optional.stream() — compose with Stream pipelines
long active = ids.stream()
    .map(this::findUser)
    .flatMap(Optional::stream)  // unwrap present ones
    .filter(User::isActive)
    .count();
Local-variable type inference (var) Java 10 Language
Old
HashMap<String, List<Employee>> byDept =
    new HashMap<String, List<Employee>>();

Iterator<Map.Entry<String, List<Employee>>> it =
    byDept.entrySet().iterator();
Modern
var byDept = new HashMap<String, List<Employee>>();

// Still statically typed — compiler infers the type.
// Only for local variables; not fields or parameters.

JEP 286 — var works where the type is obvious from the right-hand side. Use it to reduce boilerplate; avoid it when clarity suffers.

HttpClient (standard) Java 11 API
Old
URL url = new URL("https://api.example.com/data");
HttpURLConnection conn =
    (HttpURLConnection) url.openConnection();
conn.setRequestMethod("GET");
try (var r = new BufferedReader(
        new InputStreamReader(conn.getInputStream()))) {
    StringBuilder sb = new StringBuilder();
    String line;
    while ((line = r.readLine()) != null) sb.append(line);
    System.out.println(sb);
}
Modern
HttpClient client = HttpClient.newHttpClient();
HttpRequest req = HttpRequest.newBuilder()
    .uri(URI.create("https://api.example.com/data"))
    .GET().build();
HttpResponse<String> res =
    client.send(req, BodyHandlers.ofString());
System.out.println(res.body());

// Also supports async: client.sendAsync(req, ...)

JEP 321 — supports HTTP/1.1, HTTP/2, WebSockets and async out of the box. Replaces the old HttpURLConnection.

Switch expressions Java 14 Language
Old
int numDays;
switch (month) {
    case JANUARY: case MARCH: case MAY:
    case JULY: case AUGUST: case OCTOBER:
    case DECEMBER:
        numDays = 31; break;
    case FEBRUARY:
        numDays = year % 4 == 0 ? 29 : 28; break;
    default:
        numDays = 30;
}
Modern
int numDays = switch (month) {
    case JANUARY, MARCH, MAY,
         JULY, AUGUST, OCTOBER,
         DECEMBER              -> 31;
    case FEBRUARY              -> year % 4 == 0 ? 29 : 28;
    default                    -> 30;
};
// Expression — result assigned directly, no break needed

JEP 361 — the -> arm never falls through. Use yield inside a block arm when multiple statements are needed before the result.

Modern

JEP 358 — enabled by default since Java 14. Flag: -XX:+ShowCodeDetailsInExceptionMessages (on by default in 14+).

Records Java 16 Language
Old
class Point {
    private final int x, y;
    Point(int x, int y) { this.x = x; this.y = y; }
    int x() { return x; }
    int y() { return y; }
    @Override public boolean equals(Object o) { /* ... */ }
    @Override public int hashCode() { /* ... */ }
    @Override public String toString() {
        return "Point[" + x + ", " + y + "]";
    }
}
Modern
record Point(int x, int y) {}

// Constructor, accessors (x(), y()), equals,
// hashCode, toString — all auto-generated.

JEP 395 — ideal for DTOs, value objects and stream pipeline elements. Add a compact constructor to validate: record Range(int lo, int hi) { Range { if (lo > hi) throw ... } }

Pattern matching for instanceof Java 16 Language
Old
if (obj instanceof String) {
    String s = (String) obj;   // redundant cast
    System.out.println(s.toUpperCase());
}

if (shape instanceof Circle) {
    Circle c = (Circle) shape;
    draw(c.radius());
}
Modern
if (obj instanceof String s) {
    System.out.println(s.toUpperCase());
}

if (shape instanceof Circle c) {
    draw(c.radius());
}
// s and c are in scope and already cast — no extra line

JEP 394 — the pattern variable is scoped to the true branch. Combine with &&: if (obj instanceof String s && !s.isBlank())

Sealed classes Java 17 Language
Old
// Anyone can extend Vehicle anywhere in the codebase
abstract class Vehicle {}
class Car   extends Vehicle {}
class Truck extends Vehicle {}
// switch on Vehicle needs a default — can't be exhaustive
Modern
sealed interface Vehicle permits Car, Truck, Van {}
record Car(String model)   implements Vehicle {}
record Truck(int payload)  implements Vehicle {}
record Van(int seats)      implements Vehicle {}

// Pattern switch can now be exhaustive — no default needed
double tax(Vehicle v) {
    return switch (v) {
        case Car c   -> 0.1 * c.price();
        case Truck t -> 0.2 * t.payload();
        case Van va  -> 0.15 * va.seats();
    };
}

JEP 409 — the permits clause is inferred when permitted classes are in the same file. Works with interfaces and abstract classes.

Pattern matching for switch Java 21 Language
Old
String describe(Object obj) {
    if (obj instanceof Integer i)
        return "int: " + i;
    if (obj instanceof String s)
        return "str: " + s.toUpperCase();
    if (obj instanceof Double d)
        return "dbl: " + d;
    throw new IllegalArgumentException();
}
Modern
String describe(Object obj) {
    return switch (obj) {
        case Integer i -> "int: " + i;
        case String s  -> "str: " + s.toUpperCase();
        case Double d  -> "dbl: " + d;
        case null      -> "null";
        default        -> "unknown";
    };
}

JEP 441 — add guards with when: case String s when s.length() > 10 -> "long". Null handling is explicit — no more silent NPE in switch.

Record patterns Java 21 Language
Old

}
Modern

if (obj instanceof Rect(Point(int x, int y), Size(int w, int h))) {

}

JEP 440 — pattern deconstructs a record into its components in one step. Works in switch arms too.

Sequenced collections Java 21 API
Old
List<String> list = new ArrayList<>(List.of("a","b","c"));
String first = list.get(0);              // verbose index
String last  = list.get(list.size()-1); // error-prone

// No standard "add to front" for List
// LinkedHashMap had no last-entry accessor
Modern
List<String> list = new ArrayList<>(List.of("a","b","c"));
String first = list.getFirst();   // SequencedCollection
String last  = list.getLast();
list.addFirst("z");
list.reversed().forEach(System.out::println);

// Works on List, Deque, LinkedHashMap, LinkedHashSet

JEP 431 — adds SequencedCollection, SequencedSet, SequencedMap interfaces. Retrofit applied to existing JDK types.

Virtual threads Java 21 Concurrency
Old
// 10,000 platform threads ≈ 10 GB of stack + OS overhead
ExecutorService pool = Executors.newFixedThreadPool(200);
for (int i = 0; i < 10_000; i++) {
    pool.submit(() -> callExternalApi());
}
// Must size the pool carefully — too small = bottleneck
Modern
// 10,000 virtual threads ≈ a few MB total
try (var exec = Executors.newVirtualThreadPerTaskExecutor()) {
    for (int i = 0; i < 10_000; i++) {
        exec.submit(() -> callExternalApi());
    }
}  // waits for all tasks to finish

// Or: Thread.ofVirtual().start(runnable);

JEP 444 — virtual threads are cheap enough to create one per task. They block without tying up a platform thread (the carrier unmounts on I/O blocking calls).

Unnamed variables (_) Java 22 Language
Old
try {
    int result = Integer.parseInt(input);
} catch (NumberFormatException e) {  // 'e' never used
    log.warn("Bad input: " + input);
}

for (String ignored : list) { counter++; }
Modern
try {
    int result = Integer.parseInt(input);
} catch (NumberFormatException _) {   // explicit: unused
    log.warn("Bad input: " + input);
}

for (String _ : list) { counter++; }

// Also works in pattern switch arms:
case Point(int x, int _) -> "x=" + x;

JEP 456 — _ signals "I need the binding syntactically but don't use the value". Keeps the code honest and avoids spurious unused-variable warnings.

Stream gatherers Java 24 API
Old
// Sliding window of 3 — no built-in; manual loop required
List<List<Integer>> windows = new ArrayList<>();
for (int i = 0; i <= numbers.size() - 3; i++) {
    windows.add(numbers.subList(i, i + 3));
}
Modern
import java.util.stream.Gatherers;

List<List<Integer>> windows = numbers.stream()
    .gather(Gatherers.windowSliding(3))
    .toList();

// Fixed-size batches
List<List<Integer>> batches = numbers.stream()
    .gather(Gatherers.windowFixed(100))
    .toList();

JEP 485 — Gatherer is a composable intermediate operator. Built-ins: windowSliding, windowFixed, fold, scan, mapConcurrent. Write custom ones too.

Scoped values Java 25 Concurrency
Old
static final ThreadLocal<User> CURRENT_USER =
    new ThreadLocal<>();

CURRENT_USER.set(user);
try {
    process();
} finally {
    CURRENT_USER.remove();  // easy to forget → memory leak
}
// Shared across thread-pool reuse; mutable by child threads
Modern
static final ScopedValue<User> CURRENT_USER =
    ScopedValue.newInstance();

ScopedValue.runWhere(CURRENT_USER, user, () -> {
    process();  // CURRENT_USER visible to all callees
});
// Automatically cleared when the scope exits.
// Immutable — child threads can read, not overwrite.

JEP 487 — scoped values work well with virtual threads and structured concurrency. Unlike ThreadLocal they cannot be mutated by callees and have no risk of leaking across pool reuse.

Flexible constructor bodies Java 26 Language
Old
class Circle extends Shape {
    final double radius;
    Circle(double radius) {
        super(validate(radius));  // super() MUST be first line
        this.radius = radius;
    }
    private static double validate(double r) {
        if (r <= 0) throw new IllegalArgumentException();
        return r;
    }
}
Modern
class Circle extends Shape {
    final double radius;
    Circle(double radius) {
        // Statements allowed before super() now
        if (radius <= 0) throw new IllegalArgumentException();
        super(radius);
        this.radius = radius;
    }
}

JEP 513 — validation, logging or local variable setup can now appear before super()/this(). You still cannot read this before the super-constructor call.
